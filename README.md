# CodePath: Progressive Coding Education Platform

A comprehensive, full-stack web application designed to teach coding from absolute beginner to professional level.

## 🎯 Features

### 📚 Structured Learning Paths
- **Beginner Level**: Fundamentals, syntax, basic concepts
- **Intermediate Level**: Data structures, algorithms, design patterns
- **Advanced Level**: System design, optimization, architecture
- **Professional Level**: Industry best practices, code review, team workflows

### 🎮 Interactive Learning
- Live code editor with real-time execution
- Interactive challenges and coding problems
- Hands-on projects with guided walkthroughs
- Instant feedback and error explanations

### 📊 Progress Tracking
- User profiles with learning history
- Skill badges and achievements
- Progress dashboard with statistics
- Personalized learning recommendations

## 🛠️ Tech Stack

### Frontend: React 18 + TypeScript + Tailwind CSS
### Backend: Node.js + Express + PostgreSQL
### DevOps: Docker, GitHub Actions, AWS ready

## 🚀 Quick Start

```bash
# Using Docker (Recommended)
git clone https://github.com/zagrezunuo-hub/coding-education-app.git
cd coding-education-app
docker-compose up --build
```

Access at:
- Frontend: http://localhost:3000
- Backend: http://localhost:5000
- Database UI: http://localhost:8080
